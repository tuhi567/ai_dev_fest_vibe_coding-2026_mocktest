How to use Smart Escape

  1. Import a valid building.json or load the sample.
  2. Select an unblocked room or junction.
  3. Block/unblock nodes, corridors, or exits to simulate hazards.
  4. The route recalculates immediately using corridor costs.
  5. Reset returns all hazards to the file's original initial state.
